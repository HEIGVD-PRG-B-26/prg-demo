# prg-demo

Code montré en classe PRG-B, semestre d'automne 2026.

Chaque fichier `demos/AAAA-MM-JJ-sujet.cpp` est un programme complet et une
cible CMake du même nom : ouvrir le dossier dans CLion, choisir la cible dans
la liste de lancement, exécuter. Ajouter un fichier dans `demos/` suffit,
CMake le détecte au prochain chargement.

Standard C++20, avertissements `-Wall -Wextra -Wpedantic -Wconversion`.
